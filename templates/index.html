All terminatores above 40 are considered strong. For the default hairpin length (24), the maximum strength is 286.
The default value is 24. If your application requires a shorter or longer terminator, choose an even number between 6 and 48. You may need to increase the Acceptable Deviation, particularly when targeting high strength with a low maximum length.
The default value is 1. Increasing it can improve optimization speed but may also increase the deviation from your target strength. Avoid very low values, especially when generating very strong terminators.
The default value is 0.1. This sets how much the hairpin’s Shannon entropy can deviate from the model’s ideal value. Lowering it increases the chance of generating a terminator within the Acceptable Deviation but slows processing. Increasing it speeds up processing but may result in a strength further from the target.
The default value is 1. To generate multiple terminators with the same strength, modify the seed number while keeping all other parameters unchanged.
